# Project report outline

1. Objective: demonstrate 2D motion, Newton's second law, thrust, drag, fuel burn, and energy in a controlled landing.
2. Model and assumptions: coordinate system, planet constants, point-mass rocket, direct angle control, flat pad.
3. Equations: thrust components, atmosphere and drag, acceleration, burn rate, kinetic and potential energy.
4. Algorithm: fixed 1/120 s step, semi-implicit Euler, optional RK4, fuel-exhaustion split, ground-contact interpolation.
5. Validation: analytical free fall, hover, angled thrust, drag, mass loss, touchdown; include the measured error table from README.
6. Interactive simulation: controls, flight display, telemetry, charts, and screenshots once built.
7. Results: example successful and failed landings, planet comparison, and interpretation.
8. Limitations and improvements: simplified atmosphere, constant gravity and Isp, no torque, flat terrain; possible 3D view after the 2D game is complete.
